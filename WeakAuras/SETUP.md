# WeakAuras

## Description
__WeakAuras__ allows you to create custom visual alerts and notifications for almost anything in the game.

## Setup
1. Download the addon: `WeakAuras`
2. Log in to the game:
    - Type `/wa`.
    - Import all the desired WeakAuras:
        - [MP5 Tracker](Mp5%20tracker)
        - [Feral Charge Tracker](Feral%20Charge%20tracker)
        - [Self/Target/Focus font-size mod (12 to 10)](UnitFrame%20font-size%20mod)
        - [PartyCastBars](PartyCastBars)
