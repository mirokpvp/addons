# Addons Setup

## Downloading an addon

You may download the addons using CurseForge:
- Via Desktop: [App link](https://www.curseforge.com/download/app)
- Via website: [Website link](https://www.curseforge.com/wow/search?gameVersionTypeId=73246)

__Make sure you select TBC / BBC Anniversary version.__

## Addon list
- [Unit Frames](Zperl) - `Z-Perl BCC Anniversary (community fix - non official Zperl)`
- [Tracking enemy CDs](OmniBar%20%2B%20OmniCC) - `OmniBar` & `OmniCC`
- [Gladdy](Gladdy) - `Gladdy (Classic)`
- [Combat Indicator](CombatIndicator)
- Diminishing Return tracker for one-self and party - `Diminish DR Tracker`
- Tracking allies CDs - `OmniCD`
- Modified font - `NiceDamage (Reloaded)`
- Track damage, healing, and other stats - `Details! Damage Meter`
- MiniMap addons gathering - `MinimapButtonButton`
- QoL options - `Leatrix Plus`
- Items search - `AtlasLootClassic Anniversary`
- WeakAuras - `WeakAuras`
- ArenaPoints Calculator - `Arena Points Calculator TBC Anniversary - TBCAAPC`
- Item sets maker - `Outfitter (Retrofit)`
- Equipment swapper (with items queueing) - `MoveAny (Edit Mode, Windows and Ui)`
- Saving macros and binds - `MySlot`
- Move specific components of your UI - `MoveAny (Edit Mode, Windows and Ui)`
- AH addon - `Auctionator`
- CVar viewer - `Console Variable Manager (CVar Viewer)`
