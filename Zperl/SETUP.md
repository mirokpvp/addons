# Z-Perl

## Description
Z-Perl is a customizable __unit frame addon__ that replaces the default UI for player, target, party, and raid frames.

## Setup

1. Download the addon: `Z-Perl BCC Anniversary (community fix – non-official ZPerl)`.
2. Copy and paste [`ZPerl.lua`](ZPerl.lua) into your WoW folder:  
`_anniversary_ > WTF > Account > "Select your account" > SavedVariables`
3. Log in to the game:
   - Type __/zperl__
   - In the bottom-left of the addon, select the profile `PvP`, then press `Load`
